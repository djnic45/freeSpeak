# freeSpeak

A simple browser-based Talk Board prototype for expressing feelings and quick phrases using speech synthesis.

## Usage

Open `talk.html` in a modern browser (or host it via GitHub Pages).

- Select a feeling and intensity.
- Use quick words for common needs.
- Tap "Say it" or the play buttons to hear the message spoken aloud.

**Note:** Enable sound and disable silent mode. Early prototype for demo only — not a medical device.

## Files

- `talk.html` — The interactive board.
